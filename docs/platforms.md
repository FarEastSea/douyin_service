# 平台使用说明

## Instagram

沿用现有控制台，在“设置 → Instagram”导入正常浏览器登录后的 Cookie 文本、Netscape 或 JSON 文件，保存后自动检测。会话与固定 HTTP/HTTPS 代理加密保存，不回显。检测通过后开启采集；出口或会话变更会停止旧连接并重新检测。登录失效或 checkpoint 需要在正常浏览器人工处理。

新建下载接受帖文、Reels、作者、Story 和 Highlight 链接及分享文本；主页提交会明确确认全部可访问历史的批量范围。订阅默认选择 Posts/Reels，可在作者详情独立选择 Stories、Highlights，查看分类检查时间、历史进度和分页运行记录。历史可以暂停后续跑，轮播重试只补缺项。用户名变化、Posts/Reels 和 Story/Highlight 重叠使用平台稳定 ID 去重。文件位于统一根目录的 `Instagram/<作者ID>/<作品ID>/`，接入任务和媒体库预览。

所有 Instagram 执行共享 Redis 单通道，接口预算保存在数据库。默认请求间隔随机8–15秒、滚动每小时60次/每天500次；Posts/Reels、Stories 每6小时，Highlights 每24小时；历史每片最多50条作品或10分钟。网页可动态调整。Stories 优先于手动、到期检查和历史任务，预算不足延期；Redis 不可用时停止请求。429 采用服务端等待时间与递增冷却。这些是工程默认值，并非平台安全额度，不能保证不触发验证。

当前固定依赖为 `gallery-dl==1.32.17`。上游解析入口及本地合成数据验证与真实账号验收分开：图片、视频、混合轮播、Reels、Stories、Highlights 和已获权限的私密内容均需用当前账号少量样本验证后逐步启用。公开内容也要求有效会话；私密内容仅限该会话已有访问权限。Stories 过期后无法补回。会话检测成功只证明当时的会话身份可用，不能代表各类内容均已验收。

### 首次使用

首次启动引导完成后，所有配置统一通过 Web 设置中心维护，包括数据库、Redis、下载目录、Cookie、订阅巡检、下载参数和 X/Twitter 链路配置。网页保存值是运行时唯一权威来源。

配置保存会区分持久化与生效结果。提交后若发布或后台协调暂时失败，页面显示已保存、待自动恢复；系统会继续恢复，无需重复提交或手工重启。队列连接变更会先等待旧队列排空。

“归档与导出”页可设置相对目录和文件名模板、作品类型、发布时间范围、文件大小范围及 JSON/CSV 元数据。日期和类型不符合规则的作品不会创建下载任务；媒体大小不符合规则时任务显示为“规则跳过”。规则快照保存在任务中，因此后续修改只影响新建或明确重新下载的任务。

抖音 Cookie、UIFID、User-Agent 与可选代理会绑定为一个低并发请求上下文。Cookie 与带认证信息的代理地址只以密文保存，页面仅显示指纹、健康状态和最近失败信息；连续鉴权或风控异常会隔离该上下文，必须在设置中心检查并重新保存后才会恢复，不会自动轮换账号。首次升级会把旧明文 Cookie 自动迁移到密文档案。

X 下载按作者保存到 `<下载根目录>/<X 子目录>/<用户名>/`。每个图片或视频会建立独立资源记录，可在 X 任务列表中逐项预览或下载。X 当前要求有效 Cookie；下载器使用持久化归档避免重复获取，并内置请求间隔、429 冷却和有限重试。

TikTok 首批支持用户主页或 `@用户名` 下载，保存到 `<下载根目录>/<TikTok 子目录>/<用户名>/`。Cookie 通过设置中心加密保存，也可选用服务器 Cookie 文件；任务使用独立归档避免重复下载，并提供分页、服务端搜索、日志、取消、重试和媒体预览。

微博首批支持 UID、昵称或 `weibo.com` / `weibo.cn` 用户主页，默认下载用户 Feed 中的图片与视频，保存到 `<下载根目录>/<微博子目录>/<用户标识>/`。微博可能拒绝未登录请求；Cookie 通过设置中心加密保存，也可使用服务器 Cookie 文件。403 会显示为权限拒绝，不会误报为用户不存在。

B站首批支持数字 UID、UP 主空间、BV/av 视频、指定 `p` 参数的分P、`b23.tv` 短链接，以及包含视频的动态/opus 链接，保存到 `<下载根目录>/<B站子目录>/<来源标识>/`。下载由 yt-dlp 执行，默认单分片并发、有限重试并使用归档去重；UP 空间通常需要在设置中心保存有效 Cookie。图片或纯文字动态会明确提示暂不支持，不会伪装成下载成功。若 B站返回 352、412 或 429，任务会标记为请求受限，应等待后再重试，避免连续提交。

小红书支持 `explore`、`discovery/item`、带作品 ID 的用户链接、`xhslink.com` 短链及分享文本。单条图文、视频和实况资源保存到 `<下载根目录>/<小红书子目录>/<笔记标识>/`。Jenkins 会按 `xhs-engine.lock` 安装固定版本的隔离解析服务，不修改宝塔主项目依赖；Cookie 仍由设置中心加密管理。作者主页、扫码浏览器和订阅扫描不属于当前启用范围。

控制台按总览、任务、媒体库和订阅组织日常操作，系统与设置置底。“任务”汇总七个平台的执行状态、取消、重试与预览；“媒体库”按已索引的本地资源分页展示，提供受保护缩略图与连续预览。“系统”中的平台与存储入口核验本地引擎、Cookie、FFmpeg、下载目录及真实成功记录。存储巡检不会自动修改数据；路径重定位必须保留可确认的完整相对路径，不按同名文件猜测归属。陈旧临时文件、空文件和孤立媒体可预演后隔离到 `.quarantine/storage-maintenance/` 并保留恢复清单；确认无法找回的媒体才会把对应任务标记为失败以便重新下载。抖音作品以及能够返回互动数据的其他平台媒体可在趋势入口查看历史变化和异常增长提示。旧界面通过 `/legacy` 保留到新界面真实业务验收完成。
