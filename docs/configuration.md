# 配置说明

## 在哪里修改

首次启动时，初始化向导帮助连接数据库和 Redis，并设置管理 Token 与下载目录。之后在 Web 设置中心维护运行参数、平台会话、代理和订阅计划。

网页已保存的值优先于环境变量和代码默认值。环境变量用于首次启动，历史缓存不会覆盖网页设置。保存结果与实际生效状态会分别显示；后台连接切换暂未完成时，可在页面查看恢复进度。

## 生效时间

下载和订阅在下一次调用或调度周期读取最新配置。会话、代理或队列连接变化时，系统自动更新连接；常规配置调整无需手工重启。已创建任务的归档规则保留创建时的快照，修改规则影响新任务或明确重新下载的任务。

## 下载位置

媒体保存在统一下载根目录下的各平台子目录，例如 `douyin`、`X`、`TikTok`、`Weibo`、`Bilibili`、`Xiaohongshu` 和 `Instagram`。

修改目录时，系统按原有相对路径迁移持久化路径记录，以保持任务、历史和媒体预览的关联。迁移期间请确保新旧目录可访问，并保留媒体备份。

## 会话与敏感信息

平台 Cookie 和带认证信息的代理在设置中心加密保存，保存后不回显。Cookie 失效或出现平台验证时，需要在正常浏览器处理后重新导入。Instagram 的会话检测与采集开关相互独立；检测通过后仍需主动开启采集。

服务端环境文件、凭据密钥和数据库备份属于敏感数据，勿加入版本库或公开分享。数据库中的加密凭据需要相应密钥才能恢复，备份方法见[部署指南](deployment.md)。

## 开发配置功能

配置定义、网页表单、持久化读写和运行时读取共同组成一项配置功能。业务逻辑在实际请求或调度时获取最新值；连接类配置变更后更新连接，避免长期保留旧会话。目录设置还涉及任务、下载历史及平台资源的路径关联，可通过已有文件的预览验证迁移结果。

## 磁盘空间与通知

在“下载目录”设置中调整磁盘剩余空间预警线，默认 5 GB，填 0 关闭预警。系统每 10 分钟读取下载根目录所在磁盘的剩余空间；低于预警线时总览和洞察页会提示，并按通知设置发送提醒。空间持续不足时每 6 小时最多提醒一次，恢复后重新计时。预警只提醒，不会暂停或取消下载。

通知渠道包括 Webhook、Bark、邮件、Gotify、Telegram，以及企业微信、钉钉和飞书的群机器人。机器人地址和密钥保存后不回显。钉钉机器人使用关键词校验时，请让关键词出现在通知标题中，或改用加签。

每日摘要在设定的整点之后发送一次，汇总前一天的入库、订阅检查、当前队列和磁盘空间。可在“通知渠道与规则”中立即发送一次，用来核对内容和渠道。

## 统计与时间口径

洞察页的统计会缓存复用：媒体库规模、作者排行和任务结果约 30 分钟更新一次，入库趋势等窗口统计约 15 分钟更新一次。页面显示统计时间，点击刷新可立即重新统计（一分钟内的重复刷新仍返回上一次的结果）。缓存不可用时直接读取数据库，页面功能不受影响。

媒体库的日期分组、日期筛选，以及洞察页和每日摘要的日期，都以服务器所在时区的日期为准，不随浏览器时区变化。

PostgreSQL 的同步和异步连接均设置与应用一致的本地时间偏移，避免数据库默认 UTC 与本地时间混用；历史记录不会被自动改写。数据库切换后洞察使用独立缓存，并发重算期间优先返回上一份统计；首次统计尚未完成时会提示稍后重试。

## 存储维护保护

标记缺失文件前会重新检查文件状态及存储可读性。下载根目录不存在、不可读或为空时停止标记，避免把掉挂载当作媒体被删除；文件已经恢复或任务已经重新开始时也会跳过。空目录无法证明文件已经被删除，需要先核对实际存储。

缩略图属于可重新生成的缓存。系统每日清理超过 30 天未使用的缩略图，近期访问会更新使用时间；原始媒体不受此清理影响。

## 订阅备份

在“订阅检查”设置中导出订阅清单，得到包含各平台作者标识、名称、订阅开关和检查间隔的 JSON 文件，不含 Cookie、代理或其他凭据。

导入时先预演并显示将新增、已存在和无效的数量，确认后才写入。导入只补建缺失的抖音与 X 作者，已有作者保持不变，过程中不请求外部平台；作者的头像、作品等资料在下一次订阅检查时获取。Instagram 等平台的订阅依赖各自的会话与断点，需在对应页面重新添加。完整迁移仍以数据库备份为准，见[部署指南](deployment.md)。

## 运行记录保留

在“订阅检查”设置中调整运行记录保留天数，默认 30 天。后台每分钟分批回收过期订阅记录、会话检测记录及已结束的无媒体内部任务；文件下载任务、媒体文件、作品身份与未完成断点保留。解析阻塞状态与分页断点不会随记录清理丢失。数据库释放的空间可供后续记录复用。
