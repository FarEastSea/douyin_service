# 配置说明

## 配置基调：网页配置是唯一权威来源

- 所有可配置项都必须在 Web 设置中心提供配置入口；部署环境文件只承担首次启动和持久化载体职责。
- 业务代码每次使用配置时都必须读取网页最新保存值，禁止读取后复制到常量、模块缓存或硬编码分支中长期使用。
- 网页配置的优先级绝对高于进程环境变量、代码默认值和历史缓存；代码默认值只允许用于首次初始化。
- 配置变更后，下载、订阅检查、任务调度、媒体预览和 X/Twitter 链路必须在下一次操作时平滑使用新值。
- 下载目录采用“统一根目录 + 平台子目录”，例如 `/downloads/douyin`、`/downloads/X`、`/downloads/TikTok`、`/downloads/Weibo`、`/downloads/Bilibili` 与 `/downloads/Xiaohongshu`；修改时系统会保留相对路径，并同步迁移已有任务、历史和平台资源记录中的持久化路径。
抖音作者检查会优先识别资料中的明确封禁、处罚标记，即使昵称和头像仍存在也不会判为正常；作者列表与详情显示平台提供的处罚说明。处罚类型数字只作为平台原始类型展示，不推断未证实的具体含义。已有作者在下次订阅检查或手动同步资料时更新状态。
