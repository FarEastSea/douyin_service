# 配置说明

## 在哪里修改

首次启动时，初始化向导帮助连接数据库和 Redis，并设置管理 Token 与下载目录。之后在 Web 设置中心维护运行参数、平台会话、代理和订阅计划。

网页已保存的值优先于环境变量和代码默认值。环境变量用于首次启动，历史缓存不会覆盖网页设置。保存结果与实际生效状态会分别显示；后台连接切换暂未完成时，可在页面查看恢复进度。

## 生效时间

下载和订阅在下一次调用或调度周期读取最新配置。会话、代理或队列连接变化时，系统自动更新连接；常规配置调整无需手工重启。已创建任务的归档规则保留创建时的快照，修改规则影响新任务或明确重新下载的任务。

## 下载位置

媒体保存在统一下载根目录下的各平台子目录，例如 `douyin`、`X`、`TikTok`、`Weibo`、`Bilibili`、`Xiaohongshu` 和 `Instagram`。

修改目录时，系统按原有相对路径迁移持久化路径记录，以保持任务、历史和媒体预览的关联。迁移期间请确保新旧目录可访问，并保留媒体备份。

## 会话与敏感信息

平台 Cookie 和带认证信息的代理在设置中心加密保存，保存后不回显。Cookie 失效或出现平台验证时，需要在正常浏览器处理后重新导入。Instagram 的会话检测与采集开关相互独立；检测通过后仍需主动开启采集。

服务端环境文件、凭据密钥和数据库备份属于敏感数据，勿加入版本库或公开分享。数据库中的加密凭据需要相应密钥才能恢复，备份方法见[部署指南](deployment.md)。

## 开发配置功能

配置定义、网页表单、持久化读写和运行时读取共同组成一项配置功能。业务逻辑在实际请求或调度时获取最新值；连接类配置变更后更新连接，避免长期保留旧会话。目录设置还涉及任务、下载历史及平台资源的路径关联，可通过已有文件的预览验证迁移结果。
